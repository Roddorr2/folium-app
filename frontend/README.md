# 🎨 Folium Frontend — SPA Client

Interfaz web Single Page Application (SPA) para el catálogo público y administración de **Folium**, construida con **Vue.js 3**, **Vite** y **Tailwind CSS**.

---

## 🛠️ Tecnologías y Características

- **Vue.js 3 (Composition API):** Reactividad desacoplada y eficiente.
- **Vite:** Herramienta de compilación ultrarrápida y Hot Module Replacement (HMR).
- **Tailwind CSS:** Diseño moderno con micro-interacciones y tokens de Glassmorphism.
- **Pinia:** Gestión de estado global.
- **Vue Router:** Enrutamiento del cliente.

---

## 🚀 Guía de Desarrollo

### 1. Instalar dependencias:

```bash
npm install
```

### 2. Ejecutar en modo desarrollo:

```bash
npm run dev
```

### 3. Compilar para producción:

```bash
npm run build
```
